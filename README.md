# Weather Data Scraper

Fetches current weather for a list of cities from [Open-Meteo](https://open-meteo.com/),
processes it with pandas and exports `weather_data.csv`, with charts, an API and a dashboard.

> Work in progress, built task by task. See [`tasks/`](tasks/) for the board and
> [`AGENTS.md`](AGENTS.md) for how work is done here.
